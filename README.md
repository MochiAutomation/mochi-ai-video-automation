# Mochi AI Video Automation 🐰

An AI-powered project designed to automate the creation of engaging animated videos for children using Python.

## About the Project

Mochi AI Video Automation aims to simplify children's video production by bringing together story creation, character images, voice recordings, lip-sync, and video editing in one workflow.

Our main character, Mochi, is a cute blue bunny with floppy pink-lined ears, big green eyes, and a yellow umbrella.

## Project Goals

- Create engaging stories for children.
- Maintain consistent characters across scenes.
- Generate and organize voice recordings.
- Explore automated lip-sync.
- Combine scenes and audio into animated videos.
- Develop a repeatable video production workflow.

## Project Structure

- `assets/images/` – Character and scene images.
- `assets/audio/` – Voice recordings and audio assets.
- `scripts/` – Python automation scripts.
- `stories/` – Children's stories and scripts.
- `config/` – Project configuration files.

## Technology

- Python
- AI-assisted creative tools
- Open-source video and audio technologies

## Project Status

This project is currently under development. We are building and testing the workflow step by step.
